MARION COUNTY CANDLE STICKS — 2026 CITY CHAMPIONS

HOW TO PUBLISH FREE ON GITHUB PAGES

1. Go to github.com and create/sign in to your free account.
2. Click New repository.
3. Name it: candle-sticks-2026
4. Make it Public.
5. Click Create repository.
6. Click “uploading an existing file.”
7. Upload index.html AND the entire assets folder from this package.
8. Commit the files.
9. Open Settings → Pages.
10. Under Build and deployment, choose “Deploy from a branch.”
11. Select branch “main” and folder “/(root)”. Click Save.
12. GitHub will generate a URL similar to:
    https://YOUR-USERNAME.github.io/candle-sticks-2026/

IMPORTANT
The folder structure must stay exactly like this:

index.html
assets/
  team-photo.jpg
  candle-sticks-logo.png
  cal-rain.png

You do not need to edit any code before publishing.
